# docs 乖離点検スキル

## 目的

`AGENTS.md`・`.claude/skills`・`.claude/agents`・`README.md`・`docs` が実態から乖離していないかを点検します。

## 前提

- 点検と報告のみを行います。修正は報告後、ユーザーの合意を得て別途実施します。
- 共通ルールの実体は `AGENTS.md` です。スキル・エージェントには作業手順だけを書く方針で照合します。

## 手順

1. 各 `SKILL.md` と `.claude/agents/*.md` 内の相対リンク・パス・`npm run` コマンドを列挙し、リンク先とコマンドが実在するか確認します（コマンドは [package.json](../../../package.json) の `scripts` と照合）。
2. スキルが記載するフォルダー構成・ファイル命名規則を、実際のディレクトリと照合します。
3. `AGENTS.md` の「フォルダー構成」が実際のトップレベル構成と一致するか確認します。
4. スキル・エージェント間、およびそれらと `AGENTS.md` の間で、同じ論点の記述が食い違っていないか確認します。
5. スキル・エージェントに `AGENTS.md` と重複する共通ルールが再記述されていないか確認します。
6. `docs/docs/development-flow.md` のラベル一覧・ブランチ戦略が、`gh label list` と `AGENTS.md` に一致するか確認します。
7. 各スキルのフロントマター（`name` がディレクトリ名と一致、`description`、`argument-hint`）が揃っているか確認します。
8. 検出事項を Critical / High / Medium / Low の重大度順に、対象・内容・根拠・修正案とともに報告します。

## 非対象

- 乖離の修正作業（報告後に該当スキルへ切り替えます）。
- 本番コードのレビュー（`code-review` を使用します）。

## 完了条件

- [ ] 手順 1〜7 の各観点について、検出事項または「問題なし」が報告されている
- [ ] 検出事項が重大度順に整理されている
