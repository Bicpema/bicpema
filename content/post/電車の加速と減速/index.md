## 扱っている現象および本教材の説明

電車が一直線のレールの上を、一定の加速度で動くときの運動（等加速度直線運動）を扱います。出発時の速さを0とすると、時間 \\( t \\) [s] が経ったときの速さ \\( v \\) [m/s] は、加速度 \\( a \\) [m/s²] を用いて次のように表せます。

\\[ v = at \\]

横軸に時間 \\( t \\)、縦軸に速さ \\( v \\) をとった v-t 図では、この運動は原点を通る直線になり、**直線の傾きが加速度 \\( a \\) に等しく**なります。

- 加速度が正（\\( a > 0 \\)）のとき、速さは増え続けます（加速）。v-t 図は右上がりになります。
- 加速度が負（\\( a < 0 \\)）のとき、速さは減っていきます（減速）。v-t 図は右下がりになります。
- 電車は後退しないものとし、減速して速さが 0 になったあとは停止して、速さ 0 のままです。停止中に加速度を 0 以下にしても動き出しません。加速度を正にすると、再び加速します。

## 表示について

- 画面の上半分に電車の動きを表示します。左が負の向き、右が正の向きです。電車は画面中央に固定され、線路・枕木・距離標（出発点を 0 m とした位置）が左へ流れることで右向きの移動を表します。画面端に到達して折り返すことはありません。
- 画面の下半分に v-t 図を表示します。再生中は 0.1 秒ごとに点が追加され、軌跡が伸びていきます。
- 電車の動きの上に、現在の速さ・経過時間・加速度を数値で表示します。

## 使用方法

1. 右上の「設定」ボタンから設定パネルを開き、加速度 \\( a \\)（-5〜5 m/s²）をスライダーで設定します
2. 左下の「▶ 開始」ボタンを押してシミュレーションを開始します
3. 再生中に加速度を変えると、v-t 図の傾きが変わります
4. 「⏸ 一時停止」で一時停止し、「▶ 再開」で再開します
5. 「🔄 リセット」で初期状態に戻します

## 観察のポイント

- 加速度が正・負・0 のとき、電車の動きと v-t 図がそれぞれどうなるか確認しましょう
- v-t 図の傾きが、設定した加速度に対応していることを確認しましょう
- 加速したあとで加速度を負にして、速さが 0 になったあと電車が停止することを確認しましょう
- 停止した状態で加速度を正に変えると、再び動き出すことを確認しましょう
