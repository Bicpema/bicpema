## 扱っている現象および本教材の説明

「作用反作用の法則」（ニュートンの第3法則）とは、2つの物体が力を及ぼし合うとき、その2つの力は**大きさが等しく、向きが逆で、同じ作用線上**にあるという法則です。

このシミュレーションでは、机の上に本を積み重ねた状況を再現します。
「＋ 本を追加」「− 本を削除」ボタンを使って本の冊数を変えながら、それぞれの物体に働く力の大きさが変化するようすをリアルタイムで観察できます。

### 表示される力の作用・反作用ペア

#### ペア 1：重力（引力）の作用・反作用

- **地球が本に及ぼす力**（重力 W, 赤↓）：地球が本を鉛直下向きに引っ張る力
- **本が地球に及ぼす力**（橙↑）：本が地球を鉛直上向きに引っ張る力（反作用）

この2つの力は大きさが等しく（どちらも W = nmg）、向きが逆向きです。

#### ペア 2：接触力（垂直抗力）の作用・反作用

- **机が本に及ぼす力**（垂直抗力 N, 青↑）：机が本を鉛直上向きに押す力
- **本が机に及ぼす力**（紫↓）：本が机を鉛直下向きに押す力（反作用）

この2つの力も大きさが等しく（どちらも N = nmg）、向きが逆向きです。

### 重力と垂直抗力の違い

「重力と垂直抗力は大きさが等しいから作用反作用ではないか？」と思う方がいるかもしれませんが、これは**別の概念**です。

- **釣り合い**の2力：同じ物体に働き、合力がゼロ → 本は静止
    - 本に働く「重力 W ↓」と「垂直抗力 N ↑」は釣り合いの関係
- **作用・反作用**の2力：異なる物体に働く → 一方の作用線上に存在

本のシミュレーションで確認できるように、作用反作用の各ペアは**必ず異なる物体**に働いていることに注目しましょう。

## 対象

- 高校物理で力学を学習している学生
- 作用反作用の法則を直感的に理解したい学習者
- 釣り合いと作用反作用の違いを混同している方

## 使用方法

1. 「＋ 本を追加」ボタンをクリックして本を机に積み上げます（最大 5 冊）
2. 「− 本を削除」ボタンをクリックして本を取り除きます
3. 左パネルで机と本に働く力の矢印の変化を観察します
4. 右パネルで2つの作用・反作用ペアとその力の大きさを確認します
5. 右上の「⚙ 設定」から本1冊の質量を変更できます（0.1〜2.0 kg）

## 観察のポイント

- 本の冊数を増やすと、すべての力が同じ比率で大きくなることを確認しましょう
- 左パネルの「重力（赤↓）」と「垂直抗力（青↑）」は**同じ物体（本）**に働いていることに注目しましょう（釣り合いの力）
- 右パネルの各ペアは**異なる物体**に働いている力であることを確認しましょう（作用反作用）
- 本が 0 冊になると垂直抗力も 0 になることを確認しましょう
