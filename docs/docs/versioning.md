# バージョニング規約

## バージョン番号の形式

Bicpema は [セマンティックバージョニング](https://semver.org/lang/ja/) に準拠したバージョン番号を採用しています。

```text
v{MAJOR}.{MINOR}.{PATCH}
v{MAJOR}.{MINOR}.{PATCH}-Beta{N}
```

| フィールド | 説明                                                     |
| ---------- | -------------------------------------------------------- |
| `MAJOR`    | 破壊的な変更を含むリリース                               |
| `MINOR`    | 後方互換性のある機能追加（新規シミュレーション追加など） |
| `PATCH`    | 後方互換性のあるバグ修正・細かい修正                     |
| `Beta{N}`  | プレリリース版（`N` は 1 から始まる連番）                |

## バージョン番号の例

| タグ           | 説明                           |
| -------------- | ------------------------------ |
| `v1.0.0`       | 初回正式リリース               |
| `v1.1.0`       | 新しいシミュレーションを追加   |
| `v1.1.1`       | 既存シミュレーションのバグ修正 |
| `v2.0.0`       | 大規模な構成変更               |
| `v1.2.0-Beta1` | v1.2.0 のプレリリース第 1 号   |
| `v1.2.0-Beta2` | v1.2.0 のプレリリース第 2 号   |

## インクリメントの基準

| 変更内容                               | インクリメント先       |
| -------------------------------------- | ---------------------- |
| 新規シミュレーションの追加             | `MINOR`                |
| 既存シミュレーションの機能追加         | `MINOR`                |
| バグ修正・表示修正                     | `PATCH`                |
| 依存ライブラリの更新（互換性あり）     | `PATCH`                |
| サイト全体の構成変更・リファクタリング | `MAJOR` または `MINOR` |

## タグの作成方法

```bash
# 正式リリース
git tag v1.2.0
git push origin v1.2.0

# プレリリース
git tag v1.2.0-Beta1
git push origin v1.2.0-Beta1
```

詳細は [リリースフロー](./release-flow.md) を参照してください。

## `package.json` のバージョン

`package.json` の `version` フィールドは現在 `"0.0.0"` で固定されており、Git タグによるバージョン管理とは独立しています。
