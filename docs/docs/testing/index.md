# テスト方針

## 概要

Bicpema のテストは以下の 2 種類を行います。

| テスト種別 | ツール | 対象 |
|-----------|--------|------|
| [ユニットテスト](./unit-test.md) | Vitest | `vite/_build/` などのユーティリティ関数 |
| [UIテスト](./ui-test.md) | Playwright | シミュレーションの動作・表示確認 |

## 方針

- **シミュレーションのロジック**は p5.js のライフサイクル（`setup`/`draw`）に依存するため、ユニットテストの対象外とします
- **ユーティリティ関数**（ビルドスクリプト等）はユニットテストで検証します
- **UIの動作確認**（ボタン、スライダー、キャンバスの表示）は Playwright による E2E テストで検証します

## テストの実行

### ユニットテスト

```bash
npm test
```

詳細は [ユニットテスト](./unit-test.md) を参照してください。

### UIテスト

```bash
npx playwright test
```

詳細は [UIテスト](./ui-test.md) を参照してください。
