# テスト方針

## 概要

Bicpema のテストは以下の 2 種類を行います。

| テスト種別                       | ツール     | 対象                                                                                                                           |
| -------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------ |
| [ユニットテスト](./unit-test.md) | Vitest     | `vite/_build/` などのユーティリティ関数、p5.js に依存しない純粋な計算関数、および `state` の読み書きのみで完結する状態遷移関数 |
| [UIテスト](./ui-test.md)         | Playwright | シミュレーションの動作・表示確認                                                                                               |

## 方針

- **シミュレーションのロジック**のうち、p5インスタンス（`p`）や実DOM操作に依存しない部分（純粋な計算関数、および入力値の上限・下限クランプ、リセット、開始/停止のような `state` オブジェクトの読み書きのみで完結する状態遷移関数）は、ユニットテストの対象とします
- **p5.js のライフサイクル（`setup`/`draw`）やキャンバス描画、実DOM操作に依存する部分**はユニットテストの対象外とし、Playwright による E2E テストで検証します
- **ユーティリティ関数**（ビルドスクリプト等）はユニットテストで検証します
- **UIの動作確認**（ボタン、スライダー、キャンバスの表示）は Playwright による E2E テストで検証します

シミュレーションのロジックをユニットテスト可能にするには、p5インスタンスや実DOM要素に直接依存せず、`state` の読み書きだけで完結する関数として切り出してください（設計の考え方は [p5js-simulation-testing スキル](../../../.claude/skills/p5js-simulation-testing/SKILL.md) を参照）。

## テストの実行

### ユニットテスト

```bash
npm test
```

詳細は [ユニットテスト](./unit-test.md) を参照してください。

### UIテスト

```bash
npx playwright test
```

詳細は [UIテスト](./ui-test.md) を参照してください。
