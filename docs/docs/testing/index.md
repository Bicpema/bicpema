# テスト方針

## 概要

Bicpema のテストは以下の 2 種類を行います。

| テスト種別                       | ツール     | 対象                                                                             |
| -------------------------------- | ---------- | -------------------------------------------------------------------------------- |
| [ユニットテスト](./unit-test.md) | Vitest     | `vite/_build/` などのユーティリティ関数、および p5.js に依存しない純粋な計算関数 |
| [UIテスト](./ui-test.md)         | Playwright | シミュレーションの動作・表示確認                                                 |

## 方針

- **シミュレーションのロジック**のうち、p5インスタンス（`p`）や `state` オブジェクトの直接書き換え、DOM操作に依存しない純粋な計算関数（入力から出力を計算するだけの関数）は、ユニットテストの対象とします
- **p5.js のライフサイクル（`setup`/`draw`）やキャンバス描画、DOM操作に依存する部分**はユニットテストの対象外とし、Playwright による E2E テストで検証します
- **ユーティリティ関数**（ビルドスクリプト等）はユニットテストで検証します
- **UIの動作確認**（ボタン、スライダー、キャンバスの表示）は Playwright による E2E テストで検証します

シミュレーションのロジックをユニットテスト可能にするには、`state` の読み書きや `p.` 呼び出しを直接行わず、入出力が明確な関数として切り出してください（設計の考え方は [p5js-simulation-testing スキル](../../../.github/skills/p5js-simulation-testing/SKILL.md) を参照）。

## テストの実行

### ユニットテスト

```bash
npm test
```

詳細は [ユニットテスト](./unit-test.md) を参照してください。

### UIテスト

```bash
npx playwright test
```

詳細は [UIテスト](./ui-test.md) を参照してください。
